International standard for neural network verification

VNN-LIB

A shared language, solver interface, and capability database for checking satisfiability problems over neural networks.

Find a Solver Read the Standard 
(vnnlib-version <2.0>)

(declare-network f
  (declare-input X float32 [2,2])
  (declare-output Y float32 [1]))

(assert (and (>= X[0,0] 0.0)
             (<= X[0,0] 1.0)))
(assert (or (<= Y[0] -3.0)
            (>= Y[0] 0.0)))

Overview

What the Project Provides

Standard Query Language

VNN-LIB defines the syntax and semantics for expressing satisfiability queries over neural networks.

Solver Interface

VNN-LIB 2.0 specifies a supports command so solvers can report their capabilities consistently.

Capability Search

The solver database records reported capabilities and lets users search for compatible solver releases.

Workflow

From Solver Submission to Search Result

1

Submit

A solver developer opens a pull request with an install script for a specific release.

2

Collect

Automation installs the solver temporarily and queries the VNN-LIB 2.0 supports interface.

3

Record

The solver release capabilities are stored in the database and exposed to the website.

4

Search

Users filter by capabilities, versions, and ONNX operators to find compatible solvers.
